**  NVG Store Annual Sales Dashboard --- Excel **

 
 ## Project Overview
This project is an interactive sales analysis dashboard created entirely in Microsoft Excel for NVG Store
The dashboard provides a consolidated view of the store's 2022 sales and order performance and allows users to explore the data using interactive filters such as Month, Category, and Channel.
The project demonstrates practical Excel skills that are useful for a Data Analyst role, including dashboard design, data summarization, chart creation, slicers, and business-focused analysis.

Tool used: Microsoft Excel Project
Type: Sales & Business Analytics Dashboard Reporting 
Period: 2022 
Dataset: NVG Store sales/order data


## Business Objective
The main objective of this dashboard is to transform sales and order data into an easy-to-understand visual report that can help a business:

1. Monitor monthly sales performance
2. Compare sales with order volume
3. Understand customer demographics
4. Analyze order status
5. Compare sales across sales channels
6. Compare sales between men and women
7. Identify the top-performing states
8. Filter the dashboard by month, category, and channel
9. Quickly identify sales trends and business patterns

## How to Use the Dashboard

1. Download the Excel workbook.
2. Open it using Microsoft Excel.
3. Go to the Dashboard worksheet.
4. Use the Month slicer to select a month.
5. Use the Category slicer to select a product category.
6. Use the Channel slicer to analyze a specific sales channel.
7. Observe how the charts respond to the selected filters.
8. Use the visuals to identify trends and answer business questions.
